## Remaining external assessment

The rubric includes actual cloud deployment, production performance, browser/device testing, real notification permission/delivery and manual accessibility. Setup files and automated Chromium checks cannot stand in for that evidence. See `DEPLOYMENT.md` for the exact acceptance procedure and `VERIFICATION.md` for observed results. No deployment points or browser compatibility results are claimed without running those checks.
